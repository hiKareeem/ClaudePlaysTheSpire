## IPC Protocol — Complete Reference

### State Access
- **Main state**: `send-cmd.ps1 -Command '{"type":"GetState"}'` → returns JSON
- **State paths**: `$state.run` (HP/Gold/Deck), `$state.map` (map data), `$state.combat` (combat), `$state.rewards` (array)
- **Helper scripts**: `read-state.ps1`, `read-map.ps1`, `read-enemies.ps1`, `read-combat.ps1`

### Combat Commands
| Command | Parameters | Notes |
|---------|-----------|-------|
| `PlayCard` | `handIndex`, `targetIndex` (optional) | targetIndex for enemy targeting |
| `EndTurn` | none | Wait 3-4s after for round to process |
| `UsePotion` | `potionIndex`, `targetIndex` | Potions in combat |

### Map/Navigation
| Command | Parameters | Notes |
|---------|-----------|-------|
| `SelectMapNode` | `col`, `row` (FLAT, not nested in data) | NOT TravelMap |
| `Proceed` | none | Often needed twice after rewards |

### Rewards Flow
1. `SelectReward` with `rewardIndex` — gold first
2. `SelectReward` — potion (may need `DiscardPotion` first if full)
3. `SelectReward` — card → opens card picker
4. `SelectCardOption` with `cardIndex` — pick card, OR `SelectCardAlternative` with `alternativeIndex=0` to skip
5. `Proceed` × 2 (sometimes just 1)
- Reward structure: `kind` (Gold/Potion/Card), `index`, `amount`/`potion`/`cards`

### Shop
| Command | Parameters | Notes |
|---------|-----------|-------|
| `Purchase` | `category` (character/colorless/potion/relic), `index` | Buy items |
| `PurchaseCardRemoval` | none | Then `SelectCardsInGrid` |
| `SelectCardsInGrid` | `cardIndices` (int array) | NOT `indices` |

### Rest Site
| Command | Parameters | Notes |
|---------|-----------|-------|
| `SelectRestOption` | `optionIndex` (0=Rest, 1=Smith) | |

### Events
| Command | Parameters | Notes |
|---------|-----------|-------|
| `SelectEventOption` | `optionIndex` | May open CardGridSelection |
| `SelectCardsInGrid` | `cardIndices` | For card choice in events |

### Treasure
| Command | Parameters | Notes |
|---------|-----------|-------|
| `OpenChest` | none | |
| `SelectTreasureRelic` | `index` | |

### Neow
| Command | Parameters | Notes |
|---------|-----------|-------|
| `SelectNeowOption` | `optionIndex` | |

### Potions
| Command | Parameters | Notes |
|---------|-----------|-------|
| `DiscardPotion` | `slotIndex` (0-based) | Drop a potion to make room |
| `SkipReward` | `rewardIndex` | Skip a reward |

### Critical PowerShell Notes
- **Dollar signs ($)** are STRIPPED in `-Command` mode — MUST use `-File` with script files
- **State objects are PSObject** — use `.PSObject.Properties` to enumerate, dot notation for access
- **Hand indices shift** after every `PlayCard` — must re-read hand before each play
- **Refresh lag**: Wait 1-2s after PlayCard, 3-4s after EndTurn before reading state

## Combat Strategy Notes

### General Priority
1. **Falling Star** first (0E, applies Vuln + Weak, deals 8 dmg) — sets up damage amp
2. **Celestial Might** on Vuln targets (6×3=18, with Vuln = ~27)
3. **Beat into Shape** → generates Sovereign Blade for next turn
4. **Terraforming** before attacks for Vigor bonus
5. **Astral Pulse** for multi-enemy AoE (0E if have stars)
6. **Venerate** to replenish stars when needed

### Energy Math (CRITICAL — caused death)
- Always count energy BEFORE committing to a sequence
- After each PlayCard, remaining energy decreases — can't undo
- Example fatal mistake: planned Terraforming(1) + Strike(1) + SB(2) = 4E but only had 3E

### Enemy Threat Assessment
- **Shrinker Beetle**: Reduces attack damage significantly — prioritize killing or use debuffs
- **Slithering Strangler**: Hits for 18+ dmg — must block or kill fast
- **Vine Shambler** (61 HP): Very tanky + hits hard — need sustained damage plan
- **Flyconid** (49 HP): Moderate threat, decent HP pool

1. **Guilty curse** — supposed auto-remove after 4 combats didn't trigger (or counts differently)
2. **SkipAllRewards** — sometimes doesn't clear potion rewards, need `SelectReward` instead
3. **State refresh lag** — inconsistent timing, sometimes 1s, sometimes 4s needed
4. **Reward flow inconsistency** — sometimes needs 1 Proceed, sometimes 2
5. **`$` stripping in PowerShell `-Command`** — silently breaks star-cost reads

## Takeaways for Future Runs
1. **Energy management is #1 priority** — always verify math before playing
2. **Vigor + multi-hit cards** don't multiply well — Vigor only adds to first hit
3. **Star economy** is Regent's strength — Falling Star (0E) + Astral Pulse (0E) = free damage
4. **Block is undervalued** — died with 3 potions unused. Should use Regen Potion in tough fights
5. **Deck thinning works** — removing Strikes at shop + event was good strategy
6. **Beat into Shape + Parry** synergy is strong — free Block generation
