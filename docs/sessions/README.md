# docs/sessions/ — legacy

This directory holds ad-hoc multi-run analyses from early April 2026. It is **no longer the canonical session log location**.

For new runs:

- **Live run log** → `docs/autopilot-session-<YYYY-MM-DD>.md` (via `Write-SessionLog`, see SKILL.md §Session log format)
- **Cross-run gauntlet summary** → `docs/gauntlet-findings.md`
- **Reproducible bug/fix evidence** → `docs/verified-flows/<YYYY-MM-DD>-<slug>/README.md`

Files in this directory may contain stale protocol guidance (e.g. pre-v0.1.1 reward addressing with `rewards[i].index` instead of `rewardPosition`). Treat as historical; do not use as authoritative reference.
