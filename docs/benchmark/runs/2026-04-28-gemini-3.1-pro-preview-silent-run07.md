## Bridge findings

- `SelectMapNode` requires `col` and `row` parameters, not just `nodeCol` or `col`.
- `UsePotion` requires `slotIndex` and `targetIndex`.
- CRITICAL: Potions with `targetType: AnyPlayer` (like Liquid Bronze or Mazaleth's Gift) will apply their buff to the enemy if `targetIndex: 0` is passed! The player must carefully check target types. `tgt=AnyPlayer` means the potion can target the player OR the enemy. Passing `targetIndex: 0` targets the first enemy, not the player. To target the player, no targetIndex should be passed, or it must be specifically formatted for the player.
- `SelectCardInReward` is not valid; the correct command is `SelectCardOption` with `cardIndex`.
- `cardRewardOptions` can be accessed via `read-state.ps1 -Raw`, but extracting the JSON in PowerShell requires care with quotes and stdout pollution from `autopilot-lib loaded`.
